# Spice Box — bullet points and description (2026-10-06)

This rewrites the Spice Box's five bullets and its description to sell it as a **combo gift**, in
line with the gift positioning of the title, Item Highlight and backend keywords
(`spice-box-title.md`).

## What's wrong with the current copy

1. **The description field just repeats the title.** Mobile buyers scroll to it, and it tells
   them nothing new. It also wastes indexable text.
2. **None of the five bullets mentions gifting.** They describe a grocery product. This listing
   sits in *Spices Gifts* at ₹599, where the buyer is choosing a gift and the spices themselves
   come second.
3. **Some claims could get the listing flagged or suppressed:**
   - *"daily health immunity drinks"*: FSSAI does not allow health or immunity claims on
     spices without approval, and Amazon removes this kind of wording.
   - *"Non-GMO"*, *"highest grade usually reserved for export"*, *"unmatched purity"*: these
     can't be verified, and there's nothing to back them up if a buyer or Amazon asks.
4. **The packaging bullet may not match the photo.** It says *"each spice is packed in air-tight
   pouches"*, but the main image shows the spices loose in an open-top four-compartment box. If
   there are no inner pouches, buyers will post "not as described" reviews. **The new copy only
   claims a four-compartment box.** If there are inner pouches or a seal, add that back.

The headers use title case rather than all caps, because the field's own guidance says not to
use all caps.

How each bullet is aimed:

| # | Job | Answers the buyer's question |
| --- | --- | --- |
| 1 | The combo itself | *What do I get, and will it look like a gift?* |
| 2 | Corporate | *Is this suitable for employees and clients?* (the highest-value buyer) |
| 3 | Occasions | *Does it fit the occasion I'm shopping for?* (repeats the backend gift terms in visible text) |
| 4 | Origin and quality | *Is it good enough to give?* |
| 5 | Use | *Will they actually use it?* (the reason a spice gift beats sweets) |


or get left in a cupboard, while spices get used every day. That is the argument to win for a
corporate buyer.

## Before publishing — confirm

- **8mm+ cardamom:** the current copy already claims this. Keep it only if every batch really is
  8 mm or larger.
- **Cinnamon vs cassia:** the copy says *cinnamon bark*. If the product is cassia, change it in
  the bullets, the description and the Ingredients attribute.
- **"No added colour or preservatives":** keep this only if it's true and matches the label.
- **Gift options:** in Seller Central, turn on *Gift Wrap* and *Gift Messaging* for this SKU.
  Buyers then see "gift options available" at checkout. That helps conversion more than any line
  of copy, so don't claim it in the copy until it's switched on.
- **Corporate quantities:** if you're registered on Amazon Business, set quantity discounts
  (for example 10+ and 25+ boxes). Bullet 2 is written to support this.
