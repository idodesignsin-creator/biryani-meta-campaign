## Read this first: do not open a new ASIN for this

The current cardamom ASIN carries 28 reviews at 4.8★ and an Amazon's Choice badge. Both are
attached to the ASIN, not to the brand. A brand-new listing for the 8mm++ starts at zero reviews,
zero sales velocity and no badge, and would compete with your own page for the same keywords.

Two cases:

| Situation | What to do |
| --- | --- |
| 8mm++ **replaces** the 7-8mm stock | **Edit `B0FYY8TVNY` in place.** Same ASIN, same reviews, same badge. Only the copy and images change. |
| 8mm++ sells **alongside** the 7-8mm | Add it as a **new child under the same parent**, varying on size/grade — reviews and rank pool across the variation family (same reasoning as `listing-rewrite.md`). |

Either way the reviews follow you. Only a standalone new ASIN throws them away.

**One caveat on editing in place:** Amazon's Choice can drop when a listing's core attributes
change. It is still the right call — the badge is recoverable from sales velocity, 28 reviews are
not.

## 1. Title — 70 / 75 characters

The category caps Item Name at **75 characters** (confirmed on the garam masala SKU).

**Current** — 68 chars:
```
Spiceto Idukki Green Cardamom Whole, 100g Premium Export Grade 7-8mm
```

**Replace with** — 70 chars:
```
Spiceto Green Cardamom Whole 100g | 8mm++ Diamond Bold Elaichi, Idukki
```

Sibling sizes:
```
Spiceto Green Cardamom Whole 50g | 8mm++ Diamond Bold Elaichi, Idukki
Spiceto Green Cardamom Whole 200g | 8mm++ Diamond Bold Elaichi, Idukki
```

**What changed and why**

| Change | Reason |
| --- | --- |
| `7-8mm` → `8mm++` | The size *is* the product. Buyers search cardamom by millimetre — this is the one spec that justifies the price. |
| Added `Elaichi` | The Hindi word is a high-volume search token and the old title carried it only in the sub-line, not in the indexed Item Name. |
| Added `Bold` | The trade word for large cardamom. Buyers who know the category search it. |
| Dropped `Premium Export Grade` | 21 characters for words with no search volume. `Bold` and `8mm++` say the same thing and are searched. Keep the phrase — put it in bullet 1 and on the label. |
| `Idukki` moved to the end | Kept for trust and origin search, but it is not what buyers type first. |

**On the word "Diamond":** it is your own designation, not a certified grade — no cardamom
grading body issues a "diamond" grade. That is fine as brand language, and it pairs well with the
black-gold label, but it earns its title slot from *branding*, not search. If you ever need those
8 characters, `Diamond` is the first thing to drop, not `8mm++` or `Elaichi`.

**If you want a recognised grade word instead:** 8mm+ Alleppey Green cardamom is traded as
**AGEB (Alleppey Green Extra Bold)**. Only use `AGEB` on the listing if your supplier documents
have it — do not infer it from pod size alone.

### Claims to confirm before you publish

Everything above is either on the current listing already or stated by you. Three still need a
yes from your side:

| Claim | Where | Check |
| --- | --- | --- |
| `slow-cured` | bullet 3, highlight | Idukki cardamom is normally **flue-cured** in a curing chamber, not sun-dried. `Slow-cured` is accurate either way — but do **not** write "sun-dried", which would be wrong and would contradict the deep-green claim. |
| `No polishing, no added colour` | bullet 3 | True of your lot? Bleached and colour-treated cardamom exists, so the negative claim is worth making — but only if it holds. |
| `export-grade` | bullet 1 | Already on the live listing as "Premium Export Grade", so it is an existing stated fact. Flagged here only because the same word was unverified on the garam masala SKU. |

## 4. Backend Generic Keywords — 248 / 250 bytes

Replace, do not append. Zero overlap with the title or the highlight.

```
choti chhoti ilaichi ilaychi elaichy yelakka elakka elakkai yalakki cardamon cardomom cardamum sabut pods seeds tea coffee kheer biryani sweets baking garam masala ageb extra grade export premium aromatic natural gift hari malabar vandanmedu munnar
```

The reasoning is the same as the garam masala backend list: Amazon stems **English** morphology
but does **not** reliably connect **romanisation variants** of Indian words. `elaichi` is in the
title, so `ilaichi`, `ilaychi`, `elaichy`, `chhoti`, plus the South Indian names — `yelakka` /
`elakka` (Malayalam), `elakkai` (Tamil), `yalakki` (Kannada) — have nowhere else to live.
`cardamon` / `cardomom` / `cardamum` are the three common English misspellings.

**Deliberately excluded:** `badi elaichi`. That is black cardamom, a different product — it is
already a negative keyword in the ad account (`search-terms-findings.md`), and putting it here
would buy back the exact traffic you paid to block.

## 6. Label and image notes

The black-gold pack is an asset on the page, not just in the box:

- **Main image** must still be the product on white — Amazon policy. The black-gold jar *is* the
  product, so this works in your favour: it will stand out in a search grid full of pale pouches.
- **Put a ruler in image 2.** A photo of pods against a millimetre scale is the single most
  convincing image you can shoot for this listing, because the whole price argument is size.
  Nobody else in this category does it.
- **Image 3: side-by-side.** 6-7mm pods next to 8mm++ pods, same frame, same light.
- **Harvest date on the label.** If "Harvested 15.08.2026" is printed on the jar, photograph it.
  A claim you can see on the pack beats the same claim in a bullet.
- **Keep `8mm++` typographically consistent** between the label and the listing. If the pack says
  `8mm++` and the page says `8mm+`, that reads as two different products.
